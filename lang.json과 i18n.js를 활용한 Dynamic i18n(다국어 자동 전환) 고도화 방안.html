JSON 기반 Dynamic i18n 고도화 방안 요약

프로젝트명: culture-qr | 대상 기능: 다국어 자동 전환 엔진

작성일: 2026. 09. 11

구분: Technical Document

1. Dynamic i18n 아키텍처 및 동작 원리

• 개론 (개념 구조): 기존 고정형(Hard-coded) HTML 방식에서 탈피하여, 화면 구조(HTML)와 언어 데이터(JSON)를 분리하는 방식입니다.

• 핵심 흐름: 접속 감지 ➔ lang.json 로드 ➔ data-i18n 태그 탐색 ➔ 실시간 DOM 텍스트 교체 순으로 자동 실행됩니다.

2. 구성 요소별 상세 설계 (각론)

📁 1) 언어 딕셔너리 (`lang.json`)

한국어(ko), 영어(en), 중국어(zh-CN), 일본어(ja), 스페인어(es) 문구를 Key-Value 계층 구조 객체로 체계화하여 통합 관리

🏷️ 2) Dynamic Binding (`data-i18n` 속성)

HTML 태그에 <h1 data-i18n="header.title"> 형태로 고유 키값을 부여해 소스 수정 없이 텍스트 동적 교체 준비

⚙️ 3) 경량화 자동화 스크립트 (`i18n.js`)

외부 heavy 라이브러리 없이 Vanilla JS 기반 fetch API와 querySelectorAll을 이용해 약 20줄의 초경량 자동 전환 엔진 구현

3. 고도화 도입 시 기대 효과

🚀 글로벌 확장성

• HTML 수정 없이 lang.json 파일에 언어 팩만 추가하면 다국어 즉시 확장 완료

🛠️ 유지보수 효율성

• 메뉴명나 가격 변경 시 lang.json 1곳만 수정하면 모든 HTML 페이지에 동시 반영

😃 사용자 경험(UX) 극대화

• 국가별 관광객 접속 시 화면 전체가 자국어로 자동 변경되어 매장 이용 편의성 상승
